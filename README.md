# Cinematic Momentum Design System

A complete landing page template with momentum-based animations and a modern design system. Features smooth reveals, marquee, and contact sections.

## Features

- Momentum-based scroll animations
- Client marquee section
- Stories/case studies grid
- Contact section with email CTA
- Responsive design system

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

## Customization

Replace placeholder content in `src/components/`:
- `Contact.tsx` - Update email and company name
- `Marquee.tsx` - Add your client logos
- `Stories.tsx` - Add your case studies
